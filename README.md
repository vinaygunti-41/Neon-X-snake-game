##  About The Project

**Neon-X Snake Game** is a stylish browser-based version of the legendary Snake game with a glowing cyberpunk interface. Built completely with **pure HTML, CSS, and JavaScript**, it delivers a fast, lightweight, and immersive arcade experience without any frameworks or libraries.

> **Classic Snake gameplay meets futuristic Neon aesthetics.**

---

## ✨ Features

| 🚀 Gameplay             | 💚 UI Experience             |
| ----------------------- | ---------------------------- |
| Classic Snake Mechanics | Neon Green Cyberpunk Theme   |
| Smooth Grid Movement    | Glowing Snake & Food Effects |
| Real-Time Score Counter | Animated HUD                 |
| High Score Storage      | Glassmorphism Panels         |
| Restart Anytime         | Responsive Layout            |
| Keyboard Controls       | Modern Arcade Design         |

---

## 🎮 Game Controls

| Key               | Action                |
| ----------------- | --------------------- |
| ⬆️ Up Arrow       | Move Up               |
| ⬇️ Down Arrow     | Move Down             |
| ⬅️ Left Arrow     | Move Left             |
| ➡️ Right Arrow    | Move Right            |
| **Space / Enter** | Start or Restart Game |
